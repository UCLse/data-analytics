# UCL website branding

The course website is a teaching activity for the UCL Centre for Systems Engineering, Department of Space and Climate Physics, Faculty of Mathematical and Physical Sciences. Sayara Beg remains the course author and research lead.

## Colour palette

The website uses the current [UCL colour guidance](https://www.ucl.ac.uk/brand-and-experience/brand/visual-guidelines/colour): dark purple `#361a54`, off-white `#fafafa`, bright purple `#993bff`, mid purple `#ba82ff`, light purple `#ddbdff` and pale purple `#eedeff`. Mid purple is used for text and focus indicators against dark purple. Body text uses dark purple; secondary text uses that colour with reduced opacity.

## Official logo

`ucl-logo.svg` is the unchanged UCL secondary inverted logo from [UCL's official asset server](https://cdn.ucl.ac.uk/logos/ucl/ucl-logo--secondary-inverted.svg), retrieved on 13 October 2026. Its SHA-256 is `d177c65a6022bc49336baf7f4362cae49e59e77ab72ed830a81971b7aa9b91a9`.

The logo is hosted with the site so it remains available without a third-party image request. Its aspect ratio is preserved, with clear space on the dark-purple masthead. The full university name and department are written separately from the logo.

Follow [UCL logo guidelines](https://www.ucl.ac.uk/brand-and-experience/brand/visual-guidelines/logo/logo-guidelines) and [digital brand resources](https://www.ucl.ac.uk/brand-and-experience/experience/ucl-design-system/digital-brand-resources) when adapting the layout. Course licence notices do not grant rights in UCL's institutional logo.

## Public website boundary

The website does not link to the author's GitHub source repository. Workshop 00 directs students to obtain the approved course repository link from the lecturer. File references show locations within the student's fork.
