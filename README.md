# Heat Cascade: Python data analytics

**Course author and research lead: Sayara Beg.** Lecturer, UCL Centre for Systems Engineering, Department of Space and Climate Physics, Faculty of Mathematical and Physical Sciences. [UCL profile](https://profiles.ucl.ac.uk/106848-sayara-beg).

Heat Cascade is currently unfunded. This public release shares general teaching examples; detailed proposal architecture and work-package plans are withheld. **Credit Sayara Beg when reusing or adapting the materials.** See [attribution](ATTRIBUTION.md).

A guided beginner course connects ecosystem condition, urban heat, infrastructure pressure and decision-making under uncertainty. All supplied records and parameters are synthetic.

**Start with the [course home](heat-cascade/README.md), then complete [Workshop 00: create an account, fork and set up](heat-cascade/lessons/00-setup.md).**

The course provides 14 GitHub Markdown workshops, 13 guided notebooks, worked Python scripts, eight small input tables, a data dictionary and assessment guidance. Each workshop explains what to do, why the step matters and how to interpret the output.

GitHub displays the instructions. Python runs in local VS Code or GitHub Codespaces using the same notebook workflow. The indicative workload is 28 hours, with extra practice where needed.

[Research alignment](heat-cascade/docs/research-alignment.md) | [Data dictionary](heat-cascade/docs/data-dictionary.md) | [Instructor guide](heat-cascade/instructor/teaching-guide.md) | [Verification](heat-cascade/docs/verification.md)

The student workflow begins with a personal GitHub account and a fork of this teaching repository. Use Codespaces on that fork, or clone the fork into local VS Code. Completed notebooks and selected evidence are committed and pushed to the student's own repository.
