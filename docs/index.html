YOUR LEARNING ROUTE

One system. A complete workflow.

Each workshop explains what to do, why it matters and how to read the result. Start with your own GitHub fork. Run the code in Codespaces or a local clone in VS Code, then commit and push each workshop checkpoint.

THE EVIDENCE BOUNDARY

Fictional data. Explicit assumptions.

The exercises use 12 invented neighbourhoods and small, reproducible datasets. Their patterns are teaching examples. A model result, questionnaire change or scenario ranking needs further evidence before it can support a research or operational claim.
